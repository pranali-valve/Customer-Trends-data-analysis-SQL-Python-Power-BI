# Customer Trends data analysis SQL Python Power BI

## 📌 Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, PostgreSQL, Power BI, and Gamma. The main objective of the project is to analyze the dataset, identify meaningful insights, and present the findings through interactive dashboards, reports, and presentations.

The project covers:
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Data cleaning and transformation
- SQL analysis using PostgreSQL
- Interactive dashboard creation in Power BI
- Report and presentation preparation

---

## 📂 Dataset

The dataset used in this project contains structured business-related data for analysis.

### Dataset Features
- Numerical and categorical columns
- Missing values and duplicate records
- Business performance indicators

### Dataset Source
- Kaggle / Public Dataset

## 🔄 Project Workflow

### 1. Data Loading
- Imported dataset using Python
- Checked data structure and column information

### 2. Data Cleaning
- Removed duplicate records
- Handled missing values
- Standardized column formats
- Fixed inconsistent data entries

### 3. Exploratory Data Analysis (EDA)
- Performed statistical analysis
- Identified trends and patterns
- Created visualizations for better understanding

### 4. SQL Analysis using PostgreSQL
- Imported cleaned dataset into PostgreSQL
- Executed SQL queries for business analysis
- Used:
  - SELECT statements
  - GROUP BY
  - ORDER BY
  - Aggregate Functions
  - Joins
  - Filtering conditions

### 5. Dashboard Development
- Built interactive Power BI dashboards
- Added KPIs, charts, filters, and slicers
- Designed dashboards for business insights

### 6. Report & Presentation
- Created project report summarizing findings
- Developed presentation slides using Gamma
